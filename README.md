# 🧠 RoundTable AI

### **Don’t ask AI for an answer. Build a room that argues about it.**

RoundTable AI is a **voice-first multi-agent decision platform** where users bring a real problem, and AI dynamically creates a room of people with different **perspectives, expertise, goals, personalities, and voices**.

Instead of asking one AI:

> “What should I do?”

You ask:

> **“Who should be in the room to help me decide?”**

RoundTable AI creates that room.

---

## 🚀 The Problem

Most AI assistants try to give you **one answer**.

But real decisions rarely work that way.

When humans make important decisions, they consult different people:

- A friend
- An expert
- A critic
- A customer
- An investor
- An engineer
- A competitor
- A risk analyst

These people don't always agree.

That disagreement is valuable.

**RoundTable AI recreates this experience with AI agents.**

---

# 💡 The Core Idea

The user provides a problem, question, idea, or decision.

For example:

> **“Should I build this startup?”**

RoundTable AI can automatically create:

| AI Participant | Perspective |
|---|---|
| 💰 Investor | ROI, market potential |
| 👨‍💻 Engineer | Technical feasibility |
| 🎯 Customer | User needs |
| ⚔️ Devil's Advocate | Finds weaknesses |
| 🏢 Competitor | Competitive threats |
| 🤝 Friend | Personal perspective |
| 🧠 Moderator | Controls discussion |

Each participant has:

- Different expertise
- Different personality
- Different objectives
- Different opinions
- Different voice

The agents then **discuss, challenge, disagree and reason together**.

---

# 🎙️ Powered by ElevenLabs

Voice is not just an output layer in RoundTable AI.

**Voice is part of each AI participant's identity.**

Every agent can have a distinct voice powered by **ElevenLabs**.

For example:

> **Investor:** “I'm concerned about the customer acquisition cost.”

> **Engineer:** “I disagree. The technical infrastructure is actually quite simple.”

> **Customer:** “Both of you are missing the biggest problem. I wouldn't use this product.”

> **Devil's Advocate:** “Exactly. Let's talk about why customers wouldn't switch.”

This makes the meeting feel like a **real room full of people**, rather than a chatbot conversation.

# 🔥 What Makes RoundTable AI Different?

Generic multi-agent systems already exist.

RoundTable AI focuses on something more specific:

## **Dynamic Perspective Generation**

The system doesn't simply place predefined AI agents in every meeting.

It asks:

> **“What perspectives are necessary to properly evaluate this problem?”**

Then it constructs the room.

### Example

User:

> “Should I leave my job and start a company?”

RoundTable AI might create:

- Entrepreneur
- Financial Advisor
- Investor
- Risk Analyst
- Family Perspective
- Industry Expert
- Devil's Advocate
- Moderator

Another question could produce a completely different room.

# 3. ⚔️ Genuine Disagreement

Agents are not designed to simply agree with each other.

They can:

- Challenge arguments
- Question assumptions
- Provide counterexamples
- Defend their position
- Change their opinion
- Ask another agent questions
- Identify contradictions

The goal is not:

> “Everyone agrees.”

The goal is:

> **“The strongest arguments survive.”**

---

# 4. 🗣️ Agent-to-Agent Conversation

Agents communicate directly with each other.

Example:

```text
Investor:
I don't think the business is scalable.

Engineer:
Why do you think scalability is the primary concern?

Investor:
Because the current business model requires
high operational costs.

Engineer:
That's fair, but automation could reduce those costs.
```

This creates a natural discussion instead of isolated AI responses.

# 5. 🎤 Human-in-the-Loop

The user can:

- Challenge an agent
- Interrupt
- Change the topic
- Add information
- Remove an agent
- Add a new perspective

> **User:** “You haven't considered the customer's privacy concerns.”

# 6. ➕ Add a Perspective

One of the core features.

During a meeting, the user can say:

> **“We need a legal perspective.”**

RoundTable AI dynamically creates a Legal Advisor and gives them the existing meeting context.

The new agent joins without restarting the meeting.

---

# 7. 🧨 Challenge the Room

A special mode that forces the AI participants to attack the current conclusion.

The system asks:

> **“What could make this decision wrong?”**

Agents then search for:

- Hidden assumptions
- Risks
- Missing perspectives
- Weak evidence
- Contradictions
- Worst-case scenarios

This prevents the room from becoming an AI echo chamber.

# 🚀 Getting Started

## 1. Clone the repository

```bash
git clone <repository-url>
cd roundtable-ai
```

## 2. Install dependencies

The repository is an npm workspace (`frontend`, `backend`, `shared`). Install once, from the root:

```bash
npm install
```

## 3. Configure environment variables (optional)

Both apps run with sensible defaults. To override them, copy the documented examples:

```text
frontend/.env.example  →  frontend/.env.local
backend/.env.example   →  backend/.env
```

No API keys are needed yet: the room server currently uses a local fake LLM provider.

## 4. Start development servers

Local demo (no backend needed):

```bash
npm run dev:frontend
```

Live rooms through the room server: set `NEXT_PUBLIC_MEETING_BACKEND=live` in `frontend/.env.local`, then run both:

```bash
npm run dev:backend    # room server on http://localhost:4000
npm run dev:frontend   # app on http://localhost:3000
```

## 5. Checks

```bash
npm run typecheck   # all workspaces
npm run lint        # frontend
npm test            # shared + backend (Vitest)
npm run build       # frontend production build
```
